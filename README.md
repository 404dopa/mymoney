# تطبيق تتبع الأموال | Money Track

تطبيق احترافي متكامل لإدارة وتتبع المصاريف، الإيرادات، والإحصائيات المالية بدقة وسرعة وبواجهة داكنة مريحة وعالية التباين (Dark Solid UI).

---

## التقنيات المستخدمة (Tech Stack)

### الواجهة الأمامية (Frontend)
* **React 18** مع **TypeScript**
* **Vite** للبناء والتطوير السريع
* **React Router v6** للتنقل بين الصفحات
* **Vanilla CSS**: تصميم داكن مسطح (Dark Solid UI) خالٍ من التدرجات والمؤثرات الزائدة، مع أزرار كبيرة وعناصر سهلة اللمس (Fat-Finger Friendly).
* دعم كامل للغة العربية والاتجاه من اليمين لليسار (`dir="rtl"`).

### الواجهة الخلفية (Backend)
* **Go (Golang)** مع إطار العمل **Gin**
* معمارية برمجية نظيفة (Clean Architecture: Handlers -> Repositories -> Models -> Database)
* استجابات JSON قياسية وموحدة لجميع الطلبات والأخطاء:
  ```json
  { "success": true, "data": { ... }, "message": null }
  ```

### قاعدة البيانات (Database)
* **محلياً (Local):** **SQLite** (باستخدام محرك Pure Go مدمج `modernc.org/sqlite` بدون CGO، لا يحتاج لتثبيت أي برامج أو قواعد بيانات إضافية ويعمل محلياً فوراً).
* **على السيرفر (Railway):** **PostgreSQL** تلقائياً بمجرد توفر `DATABASE_URL`، وتخزين المبالغ المالية بنوع آمن ودقيق `NUMERIC(18,2)`.
* تهيئة الجداول وترحيل المخطط (Schema Migration) والتصنيفات الافتراضية تلقائياً عند أول تشغيل.

## خطوات التشغيل (Run Commands)

### الخطوة 1: تشغيل الخادم الخلفي (Go Backend)

افتح نافذة طرفية أولى وانتقل إلى مجلد `backend`:

```powershell
cd c:\Users\Morabaa\Desktop\visualtest2\mymoney\backend
go mod tidy
go run cmd/server/main.go
```

سيعمل الخادم تلقائياً على قاعدة بيانات SQLite المحلية `moneytrack.db` ويستمع على:
`http://localhost:8095`

---

### الخطوة 2: تشغيل الواجهة الأمامية (React Frontend)

افتح نافذة طرفية ثانية وانتقل إلى مجلد `frontend`:

```powershell
cd c:\Users\Morabaa\Desktop\visualtest2\mymoney\frontend
npm run dev
```

افتح المتصفح على الرابط:
`http://localhost:5188`

## النشر على سيرفرات Railway

التطبيق مهيأ للعمل على Railway تلقائياً:
1. عند ربط المشروع بـ Railway وإضافة خدمة **PostgreSQL**، يقوم Railway تلقائياً بحقن متغير `DATABASE_URL`.
2. سيتعرف كود الباك إند تلقائياً على رابط PostgreSQL ويقوم بالتحويل المباشر من SQLite إلى PostgreSQL، وتشغيل جداول وتصنيفات Postgres فوراً دون أي إعداد يدوي.

(سيقوم الخادم تلقائياً بإنشاء الجداول وإدخال التصنيفات الافتراضية عند أول تشغيل).

## أقسام ومميزات التطبيق

1. **صفحة المصاريف (`/expenses`)**:
   * تسجيل المصاريف مع الاسم، المبلغ، تصنيف المصروف، التاريخ، وملاحظات إضافية.
   * إمكانية إضافة نوع مصروف جديد فورياً من داخل النموذج.
   * عرض المصاريف على شكل بطاقات كبيرة واضحة.
   * الضغط على أي بطاقة لعرض تفاصيلها كاملة، مع أزرار التعديل والحذف وتأكيد الحذف.
   * بحث فوري وتصفية حسب الشهر وحسب نوع المصروف.

2. **صفحة الإيرادات (`/income`)**:
   * تسجيل مصادر الدخل (رواتب، مبيعات، مشاريع، استثمارات...).
   * إنشاء أنواع إيرادات جديدة بنقرة واحدة.
   * عرض البطاقات، التفاصيل، التعديل والحذف مع مربع حوار التأكيد.
   * تصفية حسب الشهر والنوع والبحث الفوري.

3. **صفحة الإحصائيات (`/statistics`)**:
   * بطاقات إجمالية كبيرة: **إجمالي الإيرادات**، **إجمالي المصاريف**، و**الرصيد** (`الرصيد = الإيرادات - المصاريف`).
   * تصفية الإحصائيات حسب الشهر (أو كل الأشهر) وتصفية نوع المصروف.
   * إحصائيات المصاريف مقسمة حسب النوع قابلة للنقر.
   * إحصائيات الإيرادات مقسمة حسب النوع قابلة للنقر.
   * عند النقر على أي نوع، تظهر قائمة المعاملات المرتبطة به بالتاريخ والمبلغ وتفاصيلها.
